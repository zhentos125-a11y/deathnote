## Возможности

### Тетрадь смерти

- **Особый предмет** — `WRITABLE_BOOK` с `PersistentDataContainer`-меткой `death_note`, `unbreakable`, скрытыми `ATTRIBUTES`, `ENCHANTS`, `DYE`.
- **Отображаемое имя** — MiniMessage `<gradient:#3d0a0a:#a01010><bold>Тетрадь смерти</bold></gradient>`.
- **Lore** — настраивается в `item.lore`, тоже MiniMessage.
- **Автор** — `item.author` (по умолчанию пустой).
- **Страницы** — пустые при выдаче; можно писать что угодно.
- **Распознавание** — только по PDC-метке, поэтому обычные книги и книги, переименованные на наковальне, не считаются тетрадью.

### Механика убийства

- **Подпись книги** — `PlayerEditBookEvent` с `isSigning() == true` — это нажатие «Готово».
- **Парсинг ника** — из страниц:
  - **Точное совпадение** с ником игрока в сети приоритетно.
  - Поддержка вариантов: `Steve`, `Ник: Steve`, `"Steve"`, `«Steve»`, `Steve_`.
  - Удаление цветовых кодов (`§`, `&`), кавычек, лишних символов.
  - Разделение по `\n` и по пробелам.
- **Мгновенная смерть** — `victim.damage(Double.MAX_VALUE, writer)` (если `show-killer`) + fallback `victim.setHealth(0)`.
- **Очистка книги** — `event.setCancelled(true)` + `refresh(writer, slot)` в следующем тике (чтобы новый предмет не был перезаписан сервером).
- **Надёжность слота** — `resolveSlot`:
  - Берёт слот из пакета (`event.getSlot()`).
  - Если слот недостоверен — ищет **единственную** тетрадь в инвентаре.
  - Если тетрадей несколько — возвращает `-1` (не убиваем, чтобы не задеть не того).
  - Проверяет `off_hand` (слот 40).
- **`always-clear`** — очищать книгу, даже если жертва не найдена.

### Защиты

- **`allow-self-kill`** — разрешить убить самого себя.
- **`immune-permission`** — `deathnote.immune` защищает игрока от тетради.
- **GameMode** — креатив и спектатор неуязвимы.
- **`isInvulnerable()`** — игрок в неуязвимости не убивается.
- **`cooldown`** — задержка между использованиями (в секундах).
- **`drop-on-death`** — тетрадь не выпадает на землю при смерти (по умолчанию).

### Визуал и фидбек

- **ActionBar** — при получении тетради, при пустой книге, при успешной записи.
- **Title** — не используется (только ActionBar).
- **Звуки:**
  - `ENTITY_ITEM_PICKUP` — при получении/сбросе.
  - `UI_TOAST_CHALLENGE_COMPLETE` — при успешном убийстве.
- **Сообщения** — MiniMessage с префиксом (две строки: название + домен), для `actionbar-*` — без префикса (через `no-prefix`).

### Уборка

- **`lastUse`** — `PlayerQuitEvent` удаляет кулдаун игрока.
- **`onDeath`** — удаляет тетради из дропа, если `drop-on-death: false`.

### Локализация (MiniMessage)

- **`prefix`** — список строк, добавляется ко всем сообщениям, кроме путей из `no-prefix`.
- **`no-prefix`** — префикс не добавляется (используется для `actionbar-*`).
- **`messages.*`** — все сообщения с MiniMessage-форматированием.
- **Placeholder-теги** — `<target>`, `<sender>`, `<killer>`, `<time>`.

## Установка

1. Скачайте `DeathNote-1.0.0.jar`.
2. Положите в `plugins/`.
3. Перезапустите сервер.
4. (Опционально) настройте `plugins/DeathNote/config.yml`.
5. Выдайте тетрадь: `/deathnote` или `/deathnote <ник>`.

**Требования:**
- Paper 1.21.11+
- Java 21+
- Никаких внешних зависимостей (Adventure API входит в Paper).

---

## Использование

1. Игрок получает тетрадь: `/deathnote` (себе) или `/deathnote <ник>` (другому).
2. Открывает её — пустая writable-книга.
3. Пишет ник жертвы на первой странице (можно `Ник: Steve`, `"Steve"`, `Steve`).
4. Нажимает **«Готово»** (подпись книги).
5. Жертва мгновенно погибает, тетрадь становится чистой и готовой к следующей записи.

## 🎮 Команды

### `/deathnote` (`/dn`, `/notebook`)

| Команда | Права | Описание |
|---|---|---|
| `/deathnote` | `deathnote.use` | Выдать тетрадь себе |
| `/deathnote <ник>` | `deathnote.others` | Выдать тетрадь другому |
| `/deathnote reset` | `deathnote.use` | Заменить все свои тетради на чистые |
| `/deathnote reload` | `deathnote.reload` | Перезагрузить конфиг |

- **Tab-completion** — `reset`, `reload`, список онлайн-игроков (в зависимости от прав).
